# Virtual Mouse Using Hand Gesture

Control your computer mouse using hand gestures detected via webcam — no physical mouse needed.

## Tech Stack
- Python, OpenCV, MediaPipe, PyAutoGUI

## Features
- Hand tracking via webcam
- Gesture-based cursor movement
- Click detection using finger gestures

## Getting Started
```bash
pip install opencv-python mediapipe pyautogui
python "Virtual Mouse.py"
```
